# Pharos RWA Oracle Monitor

A lightweight monitoring tool designed to ensure the integrity and synchronization of Real-World Asset (RWA) price feeds on the **Pharos Network**.

## Features
* **Real-time Integrity Checks:** Monitor block-data consistency.
* **Oracle Deviation Tracking:** Monitor price feed stability for Gold/USD and other RWA pairs.
* **Institutional Trust:** Provides transparent logs for RWA providers.
